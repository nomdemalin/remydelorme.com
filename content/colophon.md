The pages are plain files. A static site generator turns them into more plain files. Then they sit here.

The display face is Limelight. The text face is Cormorant Garamond. Both are open licence and both are served from this address, nowhere else.

There is no tracking. There are no cookies. I do not know you are here, and I prefer it that way.

There is a feed for the [notes](@/notes/_index.md), in Atom. It works like this page does: quietly.

This is version {{ config.extra.version }}. The number goes up when something changes.
